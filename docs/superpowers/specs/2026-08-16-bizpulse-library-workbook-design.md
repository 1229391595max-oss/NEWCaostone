# BizPulse BP 资料库工作簿设计

状态：已获用户批准，待实施

文档版本：1.0

## 1. 目的

把 BP 资料库从“同时铺开所有表格预览卡片”改为可随数据量增长的工作簿界面，
同时消除“版本 1”被误解为软件版本的问题。Viewer 和 Operator 都能浏览完整的
当前数据集；Viewer 保持只读，Operator 保留版本历史和导出能力。

## 2. 数据集命名

- 普通界面不再把 `Version 1 / 版本 1` 作为当前资料库主标题。
- 当前资料库统一显示为 `Current dataset / 当前数据集`。
- 数据期间、店铺数、SKU 数和总行数继续作为当前数据集摘要。
- 内部 `dataset_version_id` 和 `version_number` 继续作为不可变计算、审计、导出和
  历史选择的权威标识，但不暴露技术 ID。
- Operator 存在多个版本时，历史选择器使用 `Imported dataset · {date}` /
  `导入数据集 · {date}`；当导入时间不可用时，退化为 `Import {number}` /
  `第 {number} 次导入`。版本号只作为历史上下文，不再像软件版本一样突出。
- Viewer 只看到已激活的共享当前数据集，不显示历史切换器。

## 3. 工作簿信息架构

资料库详情采用“顶部表格标签 + 单张详细表格 + 行详情抽屉”的混合结构：

1. 顶部显示当前数据集摘要；
2. 表格标签按稳定顺序列出全部 BP 标准表，标签包含本地化名称和行数；
3. 标签区可横向滚动，键盘可操作；表格过多时不会撑宽页面；
4. 内容区一次只渲染当前选中的一张表；
5. 桌面表格采用固定表头、表格内部横向滚动和统一行高；
6. 点击任意数据行，从右侧打开行详情抽屉并展示该行全部字段；
7. 抽屉可以通过关闭按钮或 `Escape` 关闭，焦点返回原行；
8. 窄屏保留可横向滚动的标签和表格，不产生页面级横向溢出。

默认选中第一张有数据的表；同一页面会话内切换标签后保留当前选择。

## 4. 大数据量处理

- 详细表格必须支持浏览全部规范化数据，不以现有少量 `preview` 记录冒充完整表。
- 服务端提供精确数据集、精确表角色的只读分页接口。
- 默认每页 50 行；允许选择 25、50 或 100 行；服务端拒绝越界页容量。
- 响应包含 `columns`、`rows`、`page`、`page_size`、`total_rows` 和 `total_pages`。
- 切换表格或页容量时回到第 1 页；翻页不重新加载整个资料库详情。
- Viewer 和 Operator 使用相同分页语义，但授权路由保持分离：Viewer 只能访问已激活
  的共享发布数据集，Operator 只能访问其获授权工作区和明确版本。
- 第一阶段提供分页、横向滚动和行详情；搜索、筛选、排序和列显隐作为后续增强，
  不在本次界面上放置无行为按钮。

## 5. 页面状态与错误

- 表格加载时只让详细表格区域进入 busy 状态，顶部摘要和标签保持可见。
- 空表显示本地化空状态，不渲染空白网格。
- 翻页失败时保留上一页数据并在表格区域显示可重试错误。
- 如果当前表从数据集中消失，自动选中第一张仍可用的表。
- 数字显示遵守既有 UI 规则：BRL 两位小数，普通小数最多两位，整数不补小数；
  原始数据和导出精度不受影响。

## 6. 现有能力与边界

- 保留当前数据集的缺失输入提示、来源追溯和导出区域。
- 来源追溯继续采用可折叠呈现，避免与主要表格争夺首屏空间。
- Operator 保留历史数据集切换、生成 Excel 和下载功能。
- Viewer 保持只读，不能生成正式导出、发布版本、上传个人文件或触发重算。
- 本次不修改上传、确定性计算、AI、发布或数据版本权威；只增加安全的只读表格
  分页和资料库交互。

## 7. 无障碍与响应式

- 标签使用 `tablist`、`tab` 和 `tabpanel` 语义，支持方向键切换。
- 当前标签同时使用可见样式和 `aria-selected`，不能只靠颜色表达。
- 数据行是可聚焦的详情入口，并提供本地化 accessible name。
- 抽屉使用命名的 dialog 语义并管理打开、关闭和焦点恢复。
- 所有文字、空状态、分页控件、行详情和错误均支持 English / 中文即时切换。

## 8. 测试与验收

### 服务端

- 分页接口只能读取精确版本和精确表角色；不存在的版本或表返回受控错误。
- `page_size` 上限、总行数、总页数和最后一页正确。
- Viewer 未激活时不可读取；激活后只能读取共享当前数据集。
- Operator 与 Viewer 权限边界不因分页接口而放宽。

### 前端

- 当前数据集主标题不显示 `Version 1 / 版本 1`。
- 多张表只渲染一张详细表；切换标签请求并显示对应数据。
- 分页、页容量、空表、错误保持和行详情抽屉行为正确。
- 标签区和表格只在自身容器滚动，页面没有由资料库导致的横向溢出。
- Viewer 不出现导出操作；Operator 导出仍绑定精确数据集版本。
- 中英文和键盘交互通过聚焦测试与真实浏览器检查。

## 9. 非目标

- 不在本次加入表格单元格编辑、Excel 公式、列拖拽、批量修改或数据回写。
- 不在本次加入自由 SQL、客户端一次下载全部行或无上限分页。
- 不把本地测试通过描述为 Azure、Hosted 或 Production 验收。
